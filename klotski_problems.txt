# Generalized Klotski - benchmark instances
#
# Each problem:
#   problem <id>
#   size <rows> <cols>
#   exit bottom <columns>   the exit is on the bottom edge, under the listed columns
#   target <piece>          the piece that must reach the exit
#   =========
#   <rows> lines, one token per cell, separated by spaces:
#     .                     empty cell
#     number or letter      name of a piece; cells with the same token form one rectangular piece
#   =========
#
# Goal: move the target piece so that it covers the exit cells.
# Each board is enclosed between two lines of '=========' (nothing else is).
# Problems are separated by a blank line.
